# FlowSpace 产品与技术决策台账（OMP → DSH 迁移定稿）

本文档承接 OMP Studio《Agent 画布原型：决策与交付记录》（D01–D57）与《Agent 画布原型审查》（R1–R10），结合 **DeepSeek Harness (`@deepseek-ai/dsh@0.2.2-rc.3`)** 真实运行时能力与本轮方案评审结论，归档全部迁移取舍。主规范见 [设计规范](design.md)，底层包契约见 [DSH 能力分析手册](capabilities.md)。

## 一、DSH 迁移专项拍板（M01–M12）

| 编号 | 议题 | 定稿方案 | 决策依据 |
| :--- | :--- | :--- | :--- |
| **M01** | 接续方式收敛（取消「交接」） | **不做「交接（Handoff）」**；Agent → Agent 接续方式定为 **提及 Agent (`mention`)**、**共享上下文 (`share`)**、**分叉 (`fork`)** 三种 | DSH 原生 `compaction` 会原地修改源会话表面；提及（结论）、共享上下文（`atSeq` 精简过程快照）与分叉（完整历史新会话）已完整覆盖轻中重三档需求且零额外摘要开销 |
| **M02** | 完整功能卡结构与输入框消歧（A1） | 未启动草稿态显示画布任务编辑器；绑定 `SessionId` 后挂载原生嵌入式 **`conversation.content` 单主视图**；有接续入边的节点在顶栏提供独立可折叠的**「接续指令条」** | 原生 `conversation.content` 已自带消息、工具轨迹、审批与底部聊天框，取消冗余三页签可彻底解决「日常追问输入框」与「上游触发接续存稿」混淆问题 |
| **M03** | 引用胶囊位置与注入链路（A2） | 胶囊托盘挂于草稿框底部与原生 **`conversation.composer.dock`** 插槽（主对话与画布互通）；发送时由 Host **`agent/pre-step`** 统一拦截注入；**舍弃将胶囊拖入词法树句子中间的交互** | 不侵入 DSH 私有 Lexical 编辑器内部 AST，同时保证无论从画布启动、卡内回车还是主对话页发消息，待发与「始终带上」胶囊均一致生效并自动翻转为「已发」 |
| **M04** | 输入框手敲 `@` 联动范围（A3） | 仅当 `@` 选中的会话或文件**已在当前画布上有对应节点**时自动补画/复用连线；`@` 画布外普通文件保留原生行内芯片，不自动在画布空白处生成文件节点 | 兼顾画布已有对象的关系可追溯性与版面整洁，避免日常聊天 `@` 代码文件时把画布塞满无关节点 |
| **M05** | 草稿归属判定优先级与双目录绑定（B1） | 手动新建草稿归属按 **「显式连入/指定 > 当前选中项目/分支/worktree（或选中 Agent 所在归属）> 落点空间最近」** 判定；启动时保持 `session.header.cwd` 为主仓库根路径以保住原生侧栏项目归属，用 `ctx.workingDirectory.set` 切至目标 worktree；挂纯分支时先引导建 worktree | 忠实保留原方案归属体验，同时精确适配 DSH `WorkspaceEntity` 对 `header.cwd === workspace.path` 的硬校验，杜绝主目录暗中 `git checkout` 干扰并发会话 |
| **M06** | 自动结构树层级（B2） | 保留原定 **四级结构**：Git 项目为 `项目 → 分支 → worktree → Agent → 子 Agent`（分支与 worktree 默认收起，提供两个独立显隐开关）；非 Git 项目为 `项目 → Agent → 子 Agent` | 保留按分支与按检出目录双重视角审视多线开发全貌的能力，默认收起不增加首屏噪音 |
| **M07** | Changes 节点原生化 | 直接对接 DSH 原生 **`@deepseek-ai/dsh-workspace-changes`**（`/api/changes.summary`、`/api/changes.diff`）与右侧栏 **`changes-review`**；在拉出引用线或生成展示节点瞬间将 Diff 文本固化至画布存储 | 零自研采集即可获得不污染用户 Git 索引的每轮精确改动对比；连线瞬间固化快照弥补了原生临时树随 Host 重启清理的生命周期限制 |
| **M08** | Git 节点：迁移 OMP Studio Git 窗口 | 将 OMP Studio 的 Host `git-service.ts`（改走 DSH `ctx.subprocess` + `GitWriteQueue`）与前端 `GitQuickCard` + `GitWorkbench` / `GitStatusPanel` / `GitCommitGraph` / `GitPatch` 完整迁移至 FlowSpace | 复用成熟 Git 面板能力（兼顾状态/历史图谱/分屏 Diff/暂存提交/同步与条目级引用输出），同时为画布四级分支/worktree 结构提供统一后端读模型 |
| **M09** | 终端节点分期复用（C1） | **一期**复用原生 `terminalController.screen()` 提取去转义干净屏幕快照供引用并支持一键跳原生终端；**二期**在完整终端卡内接入 `terminalController.attach` 实时交互流 | 贴合 DSH 终端依附于 Session 的原生架构，先低成本跑通高频「报错输出喂给 Agent」闭环，再平滑演进卡内交互终端 |
| **M10** | 网页（Web）节点缓做 | **本阶段不做网页工具节点**（Agent 自身仍正常使用原生 `dsh-tool-web` 搜索抓取） | 规避浏览器宿主跨域 `X-Frame-Options` / CSP 拦截与桌面端原生视图脱离 DOM 缩放的边际成本，聚焦核心研发工作流 |
| **M11** | 只读消息线语义 | **消息线纯粹呈现 DSH 原生 Agent 间消息**（如 `agent-message`、`subagent-settled` 等持久化事件），原生消息怎么走就怎么呈现，Host 不拦截、不转发、不伪造 | 保持消息线 100% 反映运行时真实通信拓扑，避免与用户显式控制的「引用线 / 接续线」职责混淆 |
| **M12** | 渲染栈与三件套文档结构 | 前端采用 **React 18 + `@xyflow/react` + 自定义 SVG 双端口/中继点/双股消息线 + DSH 嵌入式活卡片**；文档按 `design.md` + `capabilities.md` + `product-decisions.md` 组织 | 与 DSH Web Client 插件体系同构复用 React Context 与 Slots，同时完整继承原型的视觉主张、手势隔离与防遮挡交互规则 |

## 二、OMP 原型 57 项决策（D01–D57）迁移对照表

| :--- | :--- | :--- | :--- |
| D01 | 实现位置 | 适配更新 | 从独立静态原型迁入真实 DSH 插件包 `@ flowspace`（包含 `host`、`client`、`typert` 三端入口） |
| D02 | 渲染技术栈 | 适配更新 | 采用 React 18 + `@xyflow/react` 管理视口、节点与嵌套组，配合自定义 SVG 连线层与原生 DOM/Slots 活卡片 |
| D03 | 首屏视口范围 | 沿用 | 首屏聚焦当前工作区可操作的主工作流；其余项目与屏外 Agent 通过侧栏、小地图与边缘提醒定位 |
| D04 | 默认主题 | 沿用 | 跟随并同步 DSH 深浅外观（默认石墨深色），无装饰性背景渐变 |
| D05 | 默认结构显隐 | 沿用 | 默认展示项目节点，分支与 worktree 默认收起并支持分别显示；显隐不影响归属与全局启动范围 |
| D06 | 滚轮与平移手势 | 沿用 | 默认滚轮缩放、空白拖拽/空格平移（设置可切滚轮平移）；展开卡片内滚动优先，`Ctrl + 滚轮` 始终缩放 |
| D07 | 工具节点密度 | 沿用 | 工具节点（Git、Changes、文件、终端）默认精简卡，按需展开或拎出浮窗查看详情 |
| D08 | Agent 完整卡结构 | 适配更新 | 草稿态显示任务编辑器，绑定 `SessionId` 后切换为原生嵌入式 `conversation.content` 单主视图 + 可折叠接续指令条（见 M02） |
| D09 | 模型与模式选择 | 适配更新 | 活会话直接复用嵌入式对话原生模型/权限/Plan 选择器；草稿态使用不随画布缩放的 Portal 弹层 |
| D10 | 低缩放智能收纳 | 沿用 | 低缩放简化未固定卡片；**手动固定、正在编辑输入、等待审批/提问/放行的卡片强制保护不收起** |
| D11 | 浮动窗口 | 适配更新 | 采用画布工作区内浮窗与左右分屏吸附层（Canvas Overlay & Split Dock），移动同一 Agent，原位留占位卡与连线 |
| D12 | 侧挂详情卡 | 沿用 | 默认复用一张详情卡跟随当前查看项，点击固定后冻结快照并允许拆出新卡对比 |
| D13 | 引用线与展示节点 | 沿用 | 引用线与胶囊托盘共存；消息/选区引出默认固定快照，Agent 输出口拉线默认跟随最新回复 |
| D14 | 空白处拉线创建 | 沿用 | 接续出口拖至空白创建下游 Agent 草稿；引用出口拖至空白创建对应展示节点 |
| D15 | 批量起点与汇合/环 | 沿用 | 批量启动只跑范围内一级可执行起始 Agent；多入边默认汇合等待本次运行全部上游；成环默认上限 3 轮 |

## 三、审查问题（R1–R10）在 DSH 架构下的根治规范

| 编号 | 原审查问题 | DSH FlowSpace 正式规范 |
| :--- | :--- | :--- |
